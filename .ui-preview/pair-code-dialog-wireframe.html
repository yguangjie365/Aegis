⑤ 交互与边界（实现要点，供你核对）

  • 拖放路径同样适用：拖到设备行松手 → 先弹这个框 → 通过后才真正发送（多文件时**只问一次**，随后逐文件发送）。
  • 免码记忆只在运行期：勾选后同一 IP 在该次服务运行期内不再弹框；服务停止→启动即恢复询问。
  • 取消 = 零副作用：取消不发任何帧、不建任务、不写日志（除一条 Cancelled 记录）。
  • 不发码能力已达上限：输入框只收 6 位、自动大写、粘贴清洗；不足 6 位时「发送」禁用。
  • 不进 URL / 不留存：配对码只经握手帧传输，不写进设置、不进历史（R-2：码不进入会被长期留存的载体）。
  • 无障碍：对话框 `role="dialog"` + `aria-modal`，Esc = 取消，焦点圈定在框内。

待你确认的点：① 弹框时机（发送前 vs 选中设备时）｜② 勾选框要不要（不要则每次都问）｜ ③ 多文件只问一次是否可接受。
